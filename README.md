# FitQuest

Sistema de gamificação para academia.

## Objetivo

Criar uma aplicação capaz de aumentar a motivação dos alunos através de elementos de jogos.

## Funcionalidades

- Cadastro simplificado de alunos;
- Check-in diário;
- Sistema de XP;
- Evolução por níveis;
- Ranking;
- Conquistas e medalhas.

## Tecnologias

Frontend:
- React

Backend:
- Node.js

Banco:
- PostgreSQL
